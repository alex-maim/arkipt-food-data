ArkiPT adaptation dated 2026-10-13: 3,339 of 3,484 source rows have numeric energy. Selected per-100-g values only; missing, trace and less-than values remain unknown. French names are preserved; no English names are invented. 402 records from the composed-dish group are a browsing shortlist, not a claim of balanced meals or allergen safety. No source portion weights: users weigh food themselves.

Energy uses EU Regulation 1169/2011 kcal, protein uses N × 6.25, carbohydrate uses Glucides (excluding fibre), fat uses Lipides, fibre uses Fibres alimentaires. Energy is stored as kcal × 4.184 for compatibility with the app's energy representation; it is not recomputed from macros. Original workbook and header identity are pinned by SHA256 in scripts/export_regional_catalogues.py. Full omission and provenance report: catalogue-report.json. Source values in the downloaded workbook are not modified.
